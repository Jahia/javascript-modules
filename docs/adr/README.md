# Architecture Decision Records

This directory holds the architecture decision records of the JavaScript Modules project, in the [MADR](https://adr.github.io/madr/) form. One file holds one decision, named `NNNN-short-title.md`.

The number is assigned when the record is merged. A record that is still under review carries the next free number, and it is renumbered before it is merged.

A record states the decision and the reasoning behind it, in terms that stay readable without the code in front of the reader. The code, the issues and the pull requests say how and when, and all three change. The record says why.

While a decision is still changing, edit the record it belongs to instead of writing a second record that supersedes the first.
